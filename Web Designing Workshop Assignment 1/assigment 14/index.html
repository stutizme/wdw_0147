Webpage Accessibility Audit

This checklist helps check the accessibility of a webpage.

Accessibility Checklist

  • Keyboard Access: Check whether all links and buttons can be accessed using the keyboard.
  • Form Labels: Check whether every form input has a proper label.
  • Heading Order: Check whether headings follow a proper order, such as h1, h2 and h3.
  • Image Alt Text: Check whether meaningful images have alternative text.
